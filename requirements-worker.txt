# ---------------------------------------------------------------------
# GPU vs CPU
# ---------------------------------------------------------------------
# Plain `pip install torch` pulls the CUDA build — roughly 19 nvidia/cuda
# packages and gigabytes of libraries. That is correct on a machine with
# an NVIDIA GPU and pure waste on one without.
#
# On a GPU machine, install torch FIRST from the wheel index matching the
# driver's CUDA version (check with `nvidia-smi`, and see
# scripts/check_env.py), then install this file:
#
#     pip install torch --index-url https://download.pytorch.org/whl/cu121
#
# On a CPU-only machine, do the same with the CPU index — much smaller
# download and a far smaller resident footprint:
#
#     pip install torch --index-url https://download.pytorch.org/whl/cpu
#
# Either way pip then treats torch as satisfied and won't re-resolve it.
# torch is intentionally left unpinned here so that choice is yours to
# make per machine; everything else is pinned like the web deps.
# ---------------------------------------------------------------------
